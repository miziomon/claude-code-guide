# Claude Code — Practical Guide

A comprehensive, hands-on guide to **Claude Code CLI** covering installation, workflow, prompt engineering, and best practices.

Available in two languages:
- **English** — [src/claude-code-guide-en.md](src/claude-code-guide-en.md)
- **Italian** — [src/claude-code-guide-it.md](src/claude-code-guide-it.md)

## About

This guide was written by **Maurizio Pelizzone** with the support of Claude Code itself.  
Version 4.23 — May 2026. Content verified against official Anthropic documentation, examples tested on **Claude Code v2.1.123**.

## Contents

The guide covers:

- Installation and initial setup
- Core workflow and everyday usage patterns
- Prompt engineering for agentic tools
- CLAUDE.md, custom Skills, and subagents
- Cost/benefit analysis and token optimization
- Real-world examples and gotchas
